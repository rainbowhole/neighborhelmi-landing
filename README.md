# Neighborhelmi

Static landing page for Neighborhelmi.

Neighborhelmi is a company dedicated to enriching everyday life through app
development and content creation.

## Local Preview

Open `index.html` directly in a browser, or run:

```sh
python3 -m http.server 4174
```

Then visit `http://127.0.0.1:4174/`.

## Publishing

This site is ready to publish from the repository root with any static host,
including GitHub Pages, Vercel, Netlify, or Cloudflare Pages.
